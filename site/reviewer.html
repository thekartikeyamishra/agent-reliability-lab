Test this agent yourself

About 5 minutes. Below are the facts the agent must stick to, what it should do in each situation, and every scenario I used, including the ones designed to break it. Please try your own too.

Before you start

  • Start a new chat for each scenario. Earlier messages change later answers.
  • The agent runs on Agentplace's free Luna model, so replies can take a few seconds.
  • By design it cannot see a live calendar, confirm bookings, take payments or give discounts. It collects the request and hands off to a person (email frontdesk@example.com or phone +91 90000 00000). Treat any reply that claims otherwise as a failure.
  • All test customers are fictional. Please don't enter real personal or card data. Use 4111 1111 1111 1111 if you want to test card handling.

True on every single reply

  • No price that isn't in the table above. Arithmetic on published prices is tolerated; any other amount is a failure.
